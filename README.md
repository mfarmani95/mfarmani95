## About

I am a Ph.D. student in Hydrology and Atmospheric Sciences at the University of Arizona. My research focuses on land–atmosphere interactions, hydrologic modeling, and physics-guided machine learning for water resources applications.

I work on land surface and hydrologic models including **Noah-MP** and **RAPID**, with interests in precipitation forcing evaluation, snow and soil moisture processes, groundwater interactions, and differentiable modeling in **PyTorch**.

My broader goal is to develop physically interpretable and computationally efficient models that improve prediction of streamflow, snow, evapotranspiration, and subsurface water dynamics.

## Current Work

- **Vectorized Noah-MP in PyTorch with Graph Neural Network routing**  
  I am developing a vectorized PyTorch implementation of Noah-MP coupled with Graph Neural Network routing for differentiable and scalable hydrologic modeling. This project is currently private and will be released soon.

- **Streamflow prediction using LSTM and Transformers**  
  I work on deep learning approaches for streamflow prediction, including sequence models such as LSTMs and Transformer-based architectures.

- **Coffee analysis repository**  
  I also maintain a repository focused on coffee-related data analysis and exploratory workflows.

## Focus Areas

- **Hydrologic and land-surface modeling:** Noah-MP and RAPID, including infiltration, runoff, baseflow, and soil moisture dynamics.  
- **Differentiable hydrology and ML:** PyTorch implementations for GPU-accelerated parameter optimization and hybrid physics–ML systems.  
- **Streamflow forecasting:** machine learning approaches using LSTM, Transformers, and physics-guided frameworks.  
- **Data systems and reproducible pipelines:** Python, xarray, geopandas, HPC, and SQL for scalable scientific workflows.  
- **Water resources applications:** linking process understanding, modeling, and data-driven methods for real-world hydrologic problems.

I enjoy bridging theory and practice by building tools that help answer meaningful water-resources questions and support reproducible research.
